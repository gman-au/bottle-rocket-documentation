# Viewing your scans

Bottle Rocket uses local storage to store copies of scanned images received via the Bottle Rocket app.

## Viewing Scans
* Login to your Bottle Rocket server.
* On the left-hand sidebar, select **My scans**.

<div class="text--center">
![My Scans](/img/sidebarMyScans.png)
</div>

* If your Bottle Rocket app has been able to successfully send scans to this server, they
should appear here. 
* For convention, they are sorted by date, with the most recent captures appearing first.
* Each entry will detail the number of pages, the capture date, as well as any [title that has been applied](../workflow-features/retitling-files.md) to the document.

<div class="text--center">
![My Scans](/img/myScansOverview.png)
</div>

* To view the options for a specific scan, click on the **...** button under the related scan.
  * Select **Details** to navigate to the scan details page.
  * Select **Delete** to delete this scan from your server.

:::danger
Deletion is **permanent** and cannot be undone.
:::

## Scan details
The details screen contains the entire set of scans for a given batch.

<div class="text--center">
![Scan Details](/img/scanDetailsOverview.png)
</div>

For each scanned image:
* Click the image to bring up a full-sized display of the image that was captured.
* Click the **download** icon to the right of the image to download the captured image to your local file system.
* Click the **trash / delete** icon to the right of the image to confirm deletion of the image.
* You can use this page to trigger a [workflow](../configure-your-server/workflows#what-are-workflows)
that you have set up previously by selecting it from the _Workflow_ dropdown and clicking the **Run Workflow** button.
